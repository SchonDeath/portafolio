# Imágenes

Los archivos `.svg` de esta carpeta son **placeholders** generados en la paleta
fría del sitio. Reemplázalos por tus imágenes reales:

| Archivo                  | Uso                       | Tamaño sugerido |
| ------------------------ | ------------------------- | --------------- |
| `portrait.svg`           | Retrato del hero          | 800 × 1000 px   |
| `project-*.svg`          | Portadas de proyecto      | 1200 × 800 px   |
| `og.svg`                 | Vista previa para compartir | 1200 × 630 px |

Al usar `.jpg`/`.webp`, actualiza también la ruta:

- Retrato y proyectos → `src/data/profile.ts`
- Imagen social → `index.html` (`og:image`)
